# Wordle but made by me

Guess the hidden five-letter word in six chances.

## Technologies Used

1. HTML
2. CSS
3. JavaScript

## Description

This is my browser-based version of Wordle. The player enters a five-letter guess and tries to find the hidden word within six attempts. The project is currently in progress: the page has a title and a five-letter input with a Submit button, while the game logic and styling are still being built.

To open the current project, open `index.html` in a web browser. No installation is needed.

## User Stories

- As a player, I want to enter a five-letter word so I can make a guess.
- As a player, I want to submit my guess so I can see how close I am.
- As a player, I want to have six chances to guess the word.
- As a player, I want feedback on my letters so I can make a better next guess.
- As a player, I want to know when I have won or run out of guesses.
